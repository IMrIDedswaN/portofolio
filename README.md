# Portofolio Dedy Setiawan

Paket situs statis siap untuk GitHub Pages. JavaScript dan CSS di folder assets merupakan hasil build. Tidak perlu menjalankan npm.

## Terbitkan
1. Ekstrak ZIP di komputer.
2. Buat repositori publik di GitHub. Gunakan nama portofolio untuk alamat username.github.io/portofolio/ atau username.github.io untuk alamat utama.
3. Pilih Add file → Upload files. Unggah isi folder hasil ekstrak, termasuk semua folder aset. Pastikan index.html berada di tingkat teratas. Commit ke main.
4. Buka Settings → Pages. Pada Build and deployment pilih Deploy from a branch, pilih main dan /(root), lalu Save.
5. Buka alamat yang ditampilkan GitHub Pages setelah deployment selesai.

## Isi
- index.html merupakan halaman utama.
- assets/ berisi kode tampilan.
- data/ berisi data proyek dan pengalaman.
- uploads/, about/ dan cv/ berisi gambar dan CV yang ditampilkan.
